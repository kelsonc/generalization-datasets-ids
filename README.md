O arquivo "atributos-nfstream" descreve os atributos extraídos dos dados brutos (arquivos PCAP) dos conjuntos de dados CIC-IDS18, CIC-IDS17 e UNSW-NB15, utilizando a ferramenta NFStream.

O arquivo "desempenho-in1-tipoAtaque-cic18.pdf" apresenta o desempenho dos modelos na classificação por tipo de ataque, considerando a influência da Intervenção IN1 (Redução de Dimensão) no conjunto de dados GenIDS-CIC18, no cenário Interset.

O arquivo "desempenho-in2-tipoAtaque-cic18.pdf" apresenta o desempenho dos modelos na classificação por tipo de ataque, considerando a influência da Intervenção IN2 (Seleção de Atributos) no conjunto de dados GenIDS-CIC18, no cenário Interset.

No arquivo "deteccao-baseline-interset.pdf" estão os gráficos que ilustram onde os modelos obtiveram os maiores índices de acertos na identificação de cada categoria de ataques.

O arquivo "mapaCalor-cic17-unsw15.pdf" apresenta os mapas de calor para facilitar a visualização dos atributos originais que contribuem mais ou menos para cada componente principal dos conjuntos de dados GenIDS-CIC17 e GenIDS-NB15.

O arquivo "pesos-chiSquare-cic17-unsw17.pdf" apresenta as tabelas e os gráficos que evidenciam a seleção dos atributos e seus respectivos pesos de significância usando a técnica do Qui-Quadrado (Intervenção IN2) nos conjuntos de dados GenIDS-CIC17 e GenIDS-NB15.

No arquivo "pesos-pca-cic17-unsw15.pdf" estão listadas as tabelas que apresentam os pesos atribuídos aos componentes principais dos conjuntos de dadoss GenIDS-CIC17 e GenIDS-NB15 na intervenção IN1 (Redução de Dimensão) utilizando o PCA.
